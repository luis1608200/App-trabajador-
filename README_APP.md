# App Trabajador — Android MVP 0.1
Proyecto Android de prueba independiente de Akasha.

Incluye entrada, salida, descanso configurable, cálculo de horas, estimación diaria con tarifa demo, propinas/comisión y navegación inicial.

GitHub Actions compila el APK de depuración y publica el artefacto **App-Trabajador-debug**.

> MVP de prueba: todavía no está conectado a backend ni representa una nómina oficial.
